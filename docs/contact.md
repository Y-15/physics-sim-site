# ✉️ お問い合わせ（Contact Us）

「**高校物理シミュレーションラボ**」をご利用いただき誠にありがとうございます。

当サイトでは、学習者の皆様により分かりやすく正確なシミュレーター・教材をお届けするため、機能の改善や解説の推敲を日々行っております。
シミュレーションの挙動の不備、数式・導出の誤植、解説へのご質問、新規機能のリクエスト、学校・学習塾での授業活用に関するご相談など、どんなことでもお気軽にお寄せください。

## 💡 よくあるご質問（FAQ）

::: info 🏫 学校の授業や学習塾・勉強会でプロジェクター投影して使用しても良いですか？
**はい、事前の許諾連絡不要で自由にご利用いただけます。**
高校の物理の授業、塾・予備校の講義、オンライン授業、自習室などで自由に画面を映してご活用ください。生徒の皆様へのURL共有も歓迎いたします。
:::

::: info 🔗 ブログやSNS、教育系ウェブサイトでリンク・紹介しても良いですか？
**はい、当サイトは完全リンクフリーです。**
トップページだけでなく、各シミュレーターページや演習問題ページへの直接リンクもご自由に設定いただけます（引用元の明記にご協力いただけますと幸いです）。
:::

::: info 🐛 シミュレーターが動かない・表示が崩れる場合は？
お使いのブラウザ（Chrome, Safari, Edge, Firefox 等）のキャッシュを更新（Ctrl+Shift+R / Cmd+Shift+R）いただくか、上記フォームよりご利用の端末環境（OSやブラウザの種類）と具体的な状況をお知らせいただけますと幸いです。
:::

::: info ⏱️ 返信にはどれくらいの日数がかかりますか？
原則として、返信用メールアドレスをご記入いただいたお問い合わせにつきましては **1〜3営業日以内** を目安に確認・返信させていただきます（内容により調査にお時間をいただく場合がございます）。
:::
