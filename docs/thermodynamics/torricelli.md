# 水銀柱と大気圧・トリチェリの真空

1643年、ガリレオの弟子であったイタリアの物理学者エヴァンジェリスタ・トリチェリは、水銀を満たしたガラス管を水銀槽に倒立させることで、人類史上初めて人工的に「真空（トリチェリの真空）」を作り出し、**目に見えない大気圧の正体**を明らかにしました。

高校物理・大学入試において、水銀柱の問題は**「流体の圧力平衡」**と**「気体の状態方程式（ボイル・シャルルの法則）」**が美しく融合する超頻出テーマです。本項では、その基礎理論から管の上下動・傾斜、入試典型例題の定石解法までを網羅的に解説します。

## 2. トリチェリの実験と大気圧

### 2.1 実験の手順と現象
長さ約 $1\text{ m}$ の一端を閉じたガラス管に水銀（密度 $\rho \approx 1.36 \times 10^4\text{ kg/m}^3$）を満たし、口を指で塞いで水銀を満たした水銀槽の中に倒立させます。
指を離すと、水銀は管の上端まで満ちたままにはならず、ある高さまで下降して静止します。このとき、ガラス管の上端に生じた空間を**トリチェリの真空（Torricelli's vacuum）**と呼びます。

### 2.2 等圧面の原理と大気圧の導出
静止している流体において、**「同一の深さ（水平面）にあるすべての点での圧力は等しい」**という等圧面の原理が成り立ちます。

水銀槽の自由液面と同じ高さにある2つの点を考えます：
- **点 A（管外の液面）**：大気によって直接押されているため、圧力は **大気圧 $P_0$**。
- **点 B（管内の液面）**：上部空間（真空：圧力 $0$）に加えて、高さ $h$ の水銀柱の重力による圧力 $\rho g h$ がかかっています。

点 A と点 B の圧力が釣り合っているため：

$$P_0 = \rho g h$$

標準大気圧（$1\text{ atm}$）のもとでは、水銀柱の高さは気温 $0^\circ\text{C}$ において常に **$h = 760\text{ mm} = 0.760\text{ m}$** となります。
$$P_0 = (1.3595 \times 10^4\text{ kg/m}^3) \times (9.80665\text{ m/s}^2) \times 0.760\text{ m} \approx \mathbf{1.013 \times 10^5\text{ Pa}}$$

ここから、圧力の単位として **$\text{mmHg}$（トル：$\text{Torr}$）** が定義されました：
$$1\text{ atm} = 760\text{ mmHg} = 1.013 \times 10^5\text{ Pa}$$

### 3.1 圧力のつり合い方程式
水銀槽の液面基準において、管内の圧力は「気体の圧力 $P$」と「水銀柱による圧力 $\rho g h$」の和です。
$$P + \rho gh = P_0$$

圧力を水銀柱の高さ換算 $[\text{mmHg}]$ で扱うと、極めてシンプルに記述できます：

$$P\text{ [mmHg]} + h\text{ [mm]} = P_0\text{ [mmHg]} \iff P = P_0 - h$$

### 3.2 ガラス管を上下させたとき、水銀柱の高さはどうなるか？
よく出題される定性判断問題です：
> **問題**：気体を封入したガラス管を少し上に引き上げると、水銀柱の高さ $h$ は「高くなる」「低くなる」「変わらない」のどれか？

**【物理的考察と解答】**
1. もし水銀柱の高さ $h$ が変わらないと仮定すると、管の上端が高くなった分、気柱の長さ $L$（体積 $V$）が増加します。
2. 温度が一定であれば、ボイルの法則 $PV = \text{const}$ より、気体の圧力 $P$ は**減少**します。
3. つり合いの式 $P + h = P_0 \iff h = P_0 - P$ において、$P$ が減少するため、右辺 $P_0 - P$ は**増加**します。
4. したがって、仮定に反して水銀柱は**押し上げられて高くなります（$h$ は増大する）**。

> 💡 **結論**：管を引き上げると、
> - 気柱の長さ $L$ は伸びる
> - 気体の圧力 $P$ は下がる
> - 水銀柱の高さ $h$ は**高くなる**（ただし管の引き上げ量ほどは上がらない）

## 4. 大学入試厳選例題

### 例題1：トリチェリ真空のガラス管の上下と傾斜（標準）

<div class="problem-card">
  <div class="problem-header">
    <span class="badge-exam">国公立大・標準レベル</span>
    <strong>問題：水銀柱の傾斜と真空の保持</strong>
  </div>
  <p>
    大気圧が $760\text{ mmHg}$ の部屋で、十分な長さの一端を閉じたガラス管を用いてトリチェリの実験を行った。
  </p>
  <ol>
    <li>ガラス管を鉛直に保ったまま、水銀槽の液面から管の上端までの高さを $800\text{ mm}$ から $850\text{ mm}$ に引き上げた。このとき、水銀柱の液面からの高さ $h$ は何 $\text{mm}$ になるか。</li>
    <li>次に、水銀柱の上端までの高さを $700\text{ mm}$ に押し下げた。管内の水銀はどうなるか。</li>
    <li>ガラス管の上端の高さを $800\text{ mm}$ に戻し、鉛直から角 $\theta = 60^\circ$ だけ傾けた。管の閉口部に真空部分が存在するとき、ガラス管に沿った水銀柱の長さ $l$ は何 $\text{mm}$ になるか。</li>
  </ol>
</div>

#### 【思考プロセス・完全解答】

**1. 引き上げた場合の水銀柱の高さ**
上部が完全なトリチェリの真空（$P = 0$）である場合、外気圧 $P_0 = 760\text{ mmHg}$ を支える水銀柱の鉛直高さは常に一定です。
管の上端が $760\text{ mm}$ より上にある限り、水銀柱の鉛直高さは変化しません。
$$h = \mathbf{760\text{ mm}}$$
（※真空部分の長さが $40\text{ mm}$ から $90\text{ mm}$ に拡大するだけです）

**2. $700\text{ mm}$ に押し下げた場合**
大気圧が支えられる水銀柱の高さは $760\text{ mm}$ ですが、管の上端までの高さが $700\text{ mm}$ しかありません。
したがって、大気圧は管の最上端まで水銀を完全に押し上げ、**管の先端まで水銀で満たされます（真空部分は消滅する）**。
このとき、管の上面は水銀から $760 - 700 = 60\text{ mmHg}$ の上向きの圧力を受けます。

**3. ガラス管を $60^\circ$ 傾けた場合**
流体の静止圧力は「鉛直方向の深さ（高さ）」によってのみ決まります。
管に沿った長さを $l$ とすると、鉛直方向の高さ $h$ は：
$$h = l \cos 60^\circ = l \times \frac{1}{2}$$
鉛直高さ $h$ は依然として大気圧と釣り合うため $h = 760\text{ mm}$ です。
$$l \times \frac{1}{2} = 760 \implies l = 760 \times 2 = \mathbf{1520\text{ mm}}$$

### 例題2：気体を封入したガラス管の引き上げ（難関大・2次方程式解法）

<div class="problem-card">
  <div class="problem-header">
    <span class="badge-exam">難関国公立大・頻出</span>
    <strong>問題：封入気体とボイルの法則の連立</strong>
  </div>
  <p>
    大気圧が $P_0 = 760\text{ mmHg}$、断面積 $S$ の一様なガラス管を水銀槽に鉛直に立てた。
    最初、液面から管の上端までの高さが $H_1 = 800\text{ mm}$ であり、上部に少量の乾燥空気が封入されていた。このときの水銀柱の高さは $h_1 = 700\text{ mm}$ であった。
    温度を一定に保ったまま、ガラス管を鉛直上方に引き上げ、液面から管の上端までの高さを $H_2 = 900\text{ mm}$ にした。
  </p>
  <ol>
    <li>最初、管内に封入されていた気体の圧力 $P_1$ [$\text{mmHg}$] を求めよ。</li>
    <li>引き上げた後の水銀柱の高さ $h_2$ [$\text{mm}$] を求めよ。</li>
  </ol>
</div>

#### 【思考プロセス・完全解答】

**1. 初期の気体圧力 $P_1$**
液面での圧力平衡より：
$$P_1 + h_1 = P_0$$
$$P_1 = P_0 - h_1 = 760 - 700 = \mathbf{60\text{ mmHg}}$$

**2. 引き上げ後の水銀柱の高さ $h_2$**
- **初期状態（状態1）**:
  - 気体圧力: $P_1 = 60\text{ mmHg}$
  - 気柱の長さ: $L_1 = H_1 - h_1 = 800 - 700 = 100\text{ mm}$
  - 気体の体積: $V_1 = S L_1 = 100 S$

- **引き上げ後の状態（状態2）**:
  - 水銀柱の高さ: $h_2$
  - 気柱の長さ: $L_2 = H_2 - h_2 = 900 - h_2$
  - 気体圧力: 液面のつり合いより $P_2 = P_0 - h_2 = 760 - h_2$
  - 気体の体積: $V_2 = S L_2 = (900 - h_2)S$

温度が一定なので、**ボイルの法則** $P_1 V_1 = P_2 V_2$ が成り立ちます：
$$60 \times 100 S = (760 - h_2)(900 - h_2) S$$
$$6000 = 684000 - 1660 h_2 + h_2^2$$
$$h_2^2 - 1660 h_2 + 678000 = 0$$

この2次方程式を解の公式で解きます：
$$h_2 = \frac{1660 \pm \sqrt{1660^2 - 4 \times 678000}}{2} = 830 \pm \sqrt{830^2 - 678000}$$
$$830^2 = 688900$$
$$830^2 - 678000 = 10900$$
$$\sqrt{10900} \approx 104.4\text{ mm}$$
$$h_2 = 830 \pm 104.4$$

物理的条件として、$h_2 < P_0 = 760\text{ mm}$ かつ $h_2 < H_2 = 900\text{ mm}$ でなければならないため、正の符号（$830 + 104.4 = 934.4$）は不適です。
$$h_2 = 830 - 104.4 = 725.6 \approx \mathbf{726\text{ mm}}$$

（※初めの $h_1 = 700\text{ mm}$ から $726\text{ mm}$ へと、$26\text{ mm}$ 水銀柱が上昇したことが数学的にも厳密に確かめられました）

## 5. まとめ

| 状態 | つり合い式（$\text{mmHg}$ 単位） | 備考 |
| :--- | :--- | :--- |
| **完全な真空** | $h = P_0$ | 管を引き上げても $h$ は一定（上端が $P_0$ 以上のとき） |
| **気体封入時** | $P + h = P_0$ | 管を引き上げると $P$ 低下に伴い **$h$ は高くなる** |
| **ガラス管の傾斜** | $h = l \cos\theta = P_0$ | 水銀柱に沿った長さは $l = \frac{P_0}{\cos\theta}$ に伸びる |
| **状態変化の連立** | $P = P_0 - h$ と $PV = nRT$ | 2次方程式を立式して $h$ または $L$ を解く |
