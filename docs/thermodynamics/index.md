# 🔥 熱力学（高校物理）完全学習マップ

<div class="lead">
「熱」とは何か？「温度」とは何か？<br>
目に見えないミクロな分子の飛び交う熱運動が、マクロな「圧力」や「体積」「仕事」を生み出します。<br>
当サイトの熱力学ラボでは、シリンダー内で激しく壁に衝突する分子運動と $P$-$V$ インジケーター図をリアルタイムに連動させ、共通テストから難関大二次試験まで完全対応する直感的理解を養います。

## 📚 熱力学 テーマ別ナビゲーション（全9分野）

<div class="topic-grid">

### 1. 状態方程式と第1法則・サイクル
* **[🔥 気体の状態変化・P-V図と熱力学第1法則](/thermodynamics/gas-law)**  
  シリンダー分子運動と $P$-$V$ グラフのリアルタイム同期シミュレーター。定積・定圧・等温・断熱の4大変化と、1周して正味の仕事を取り出す熱機関サイクルの囲む面積 $W_{\text{net}}$ と熱効率 $e = W/Q_{\text{in}}$。
* **[🔥 カルノーサイクルと熱機関の熱効率](/thermodynamics/carnot)**  
  等温膨張・断熱膨張・等温圧縮・断熱圧縮の可逆サイクル。熱効率の理論限界 $e = 1 - \frac{T_L}{T_H}$ と熱力学第2法則（クラウジウスの原理・ケルビンの原理）。
* **[🚗 オットーサイクルと4行程内燃機関の熱効率](/thermodynamics/otto-cycle)**  
  ガソリンエンジンの理論サイクル（吸気・断熱圧縮・定積加熱・断熱膨張・定積放熱・排気）。圧縮比 $r = V_1/V_2$ と理論熱効率 $\eta = 1 - 1/r^{\gamma-1}$ のピストン連動シミュレーター。

### 2. ミクロの視点・気体分子運動論
* **[🔬 気体分子運動論と二乗平均速度](/thermodynamics/kinetic-theory)**  
  立方体容器の壁への分子衝突力積から圧力 $P = \frac{1}{3}\frac{N m \overline{v^2}}{V}$ を導く5段階ステップ。絶対温度の正体（$\frac{1}{2}m\overline{v^2} = \frac{3}{2}k_B T$）と、二乗平均速度 $v_{\text{rms}} = \sqrt{\frac{3RT}{M}}$。

### 3. モル比熱・熱量保存・相転移
* **[🔥 モル比熱とマイヤーの式・断熱変化（ポアソンの法則）](/thermodynamics/heat-capacity)**  
  定積モル比熱 $C_v$、定圧モル比熱 $C_p$、マイヤーの式 $C_p - C_v = R$、比熱比 $\gamma = C_p/C_v$、断熱変化のポアソンの式 $PV^\gamma = \text{const}$。
* **[🧊 熱量保存則・比熱・潜熱と相転移加熱曲線](/thermodynamics/calorimetry)**  
  氷・水・水蒸気の相転移、融解熱（約 $334\ \text{J/g}$）・蒸発熱（約 $2260\ \text{J/g}$）、熱量保存則 $\sum Q_{\text{lost}} = \sum Q_{\text{gained}}$、温度-時間加熱曲線シミュレーター。

### 4. 気体の混合・圧力と浮力応用
* **[🧪 気体の混合と可動ピストン](/thermodynamics/gas-mixing)**  
  コックで連結された2容器の気体混合（全圧と分圧・ドルトンの法則）、断熱シリンダー内の可動ピストンの力のつり合いと熱平衡の過渡変化。
* **[🌡️ 水銀柱と大気圧・トリチェリの真空](/thermodynamics/torricelli)**  
  大気圧 $1\ \text{atm} = 760\ \text{mmHg} \approx 1.013\times 10^5\ \text{Pa}$、トリチェリの真空、U字管・J字管内の気体の圧力つり合い。
* **[🎈 気球の浮力と熱気球の浮上条件](/thermodynamics/hot-air-balloon)**  
  シャルルの法則による加熱気体の密度低下、アルキメデスの原理に基づく浮力 $F_B = \rho_{\text{air}} V g$、熱気球の最小浮上温度 $T_{\text{lift}}$ の完全導出。
