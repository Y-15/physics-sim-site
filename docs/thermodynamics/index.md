## 📚 公開中の単元・シミュレーター

### 1. 気体の状態変化と熱力学第1法則
* **[🔥 気体の状態変化・P-V図と熱力学第1法則](/thermodynamics/gas-law)**  
  シリンダー分子運動と $P$-$V$ グラフのリアルタイム同期シミュレーター。
  定積・定圧・等温・断熱の4大変化と、1周して正味の仕事を取り出す熱機関サイクルを体感的に操作できます。
  * **扱う重要トピック**:
    * 気体の状態方程式 $PV = nRT$
    * 気体分子運動論と内部エネルギー $U = \frac{3}{2}nRT$
    * 熱力学第1法則 $Q = \Delta U + W'$
    * 4大変化（定積・定圧・等温・断熱）の整理とモル比熱 $C_v, C_p$
    * $P$-$V$ グラフの囲む面積と熱効率 $e = \frac{W_{\text{net}}}{Q_{\text{in}}}$
    * オリジナル例題：直角三角形を描くサイクルの各過程表と熱効率計算

### 2. 気体分子運動論
* **[🔬 気体分子運動論と二乗平均速度](/thermodynamics/kinetic-theory)**  
  立方体容器の壁への分子衝突力積から圧力 $P = \frac{1}{3}\frac{N m \overline{v^2}}{V}$ を導く5段階ステップ。絶対温度の正体（$\frac{1}{2}m\overline{v^2} = \frac{3}{2}k_B T$）と、マクスウェル速度分布・二乗平均速度の完全理解。
