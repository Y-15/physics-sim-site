# 📝 高校物理 厳選演習問題集（全197問）

高校物理の学習において、最も重要なのは「**公式を正しく理解し、自力で立式して答えを導く力**」です。

本問題集は、数字を変えただけの重複問題を一切排除し、高校物理の全カリキュラム（力学・波動・電磁気・熱力学・原子物理）から **1問1問が本質的に異なる厳選197問の高品質オリジナル演習問題** を収録しています。基礎レベルから共通テスト・国公立二次試験レベルまで、すべての問題に **丁寧な解法手順・計算過程・立式公式**、そして **動くシミュレーターへの直通リンク** が用意されています。
