# 🛡️ プライバシーポリシー

高校物理シミュレーションラボ（以下、「当サイト」といいます）は、ユーザーの皆様に安心して学習およびシミュレーションをご利用いただけるよう、個人情報の保護および適切な取り扱いに細心の注意を払っております。本プライバシーポリシーでは、当サイトにおける情報の収集、利用目的、Cookieの取り扱い、広告配信について定めています。

## 1. 基本方針
当サイトは、教育目的の完全無料学習プラットフォームとして運営されており、個人を特定できる情報（氏名、住所、電話番号など）をユーザーの同意なく無断で収集・保管することはありません。

## 2. 広告の配信について（Google AdSense 等）

当サイトでは、第三者配信事業者（Google AdSense等）が提供する広告配信サービスを利用しています。

### 広告配信におけるCookieの利用
* Googleなどの第三者配信事業者は、Cookie（クッキー）を使用して、ユーザーが当サイトや他のウェブサイトに過去にアクセスした際の情報に基づいて適切な広告を配信します。
* Googleが広告Cookieを使用することにより、ユーザーのアクセス情報に基づいたパーソナライズ広告が当サイトおよびインターネット上のパートナーサイトに表示されます。

### パーソナライズ広告の無効化（オプトアウト）について
ユーザーは、以下の方法によりパーソナライズ広告の配信を無効化（オプトアウト）することができます：
* [Google 広告設定](https://www.google.com/settings/ads) にアクセスして、パーソナライズ広告を無効にする。
* [aboutads.info](https://www.aboutads.info/choices/) にアクセスして、第三者配信事業者がパーソナライズ広告のためにCookieを使用しないように設定する。
* お使いのブラウザの設定でCookieを無効化または削除する。

※Cookieを無効化した場合でも、当サイトの物理シミュレーターや演習問題集などの学習機能は通常通りご利用いただけます。

## 3. アクセス解析ツールについて

当サイトでは、サービスの改善、コンテンツの充実、トラフィック分析を目的として、Googleアナリティクス等のアクセス解析ツールを利用することがあります。
* これらのツールはトラフィックデータの収集のためにCookieを使用しています。
* 収集されるデータは匿名化されており、個人を特定する情報は含まれません。
* データ収集を希望されない場合は、ブラウザのCookie設定を無効化するか、[Google アナリティクス オプトアウト アドオン](https://tools.google.com/dlpage/gaoptout)をご利用ください。
