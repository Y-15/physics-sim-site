# 光の屈折・全反射とレンズの結像公式

<div class="lead">
コップの水に入れたストローは、なぜ境界面でポキッと折れ曲がって見えるのでしょうか？<br>
インターネットの超高速通信を支える光ファイバーは、なぜ光を曲がりくねったケーブルの中に閉じ込めて漏らさずに運べるのでしょうか？<br>
光が異なる物質の境界を通過するときに起きる<strong>屈折</strong>と<strong>全反射</strong>、そして眼鏡やカメラ、顕微鏡の心臓部である<strong>レンズの結像</strong>は、幾何光学の最重要テーマです。<br>
このページでは、受験頻出の「スネルの法則」から「実像・虚像の符号規約」までを動く実験室で体感的にマスターします。
</div>

## 1. 身近な現象と到達目標

### 身近な現象
* **プールや風呂の底が浅く見える**: 水の底から出た光が空気中に出るときに屈折するため、実際の深さの約 $\frac{3}{4}$ の位置に底が浮き上がって見えます。
* **光ファイバーケーブル**: ガラスやプラスチックの芯（コア）の中を、光が**全反射**を何万回も繰り返しながら減衰せずに世界中の海を越えて長距離伝送されます。
* **虫眼鏡（拡大鏡）**: 新聞の文字に虫眼鏡を近づけると大きく見えます（正立虚像）。一方、遠くの窓にかざすと壁に外の景色が逆さまに映ります（倒立実像）。

### 学習の到達目標
1. **スネルの屈折の法則**: 入射角 $\theta_1$ と屈折角 $\theta_2$、媒質の屈折率 $n_1, n_2$ の関係式 $n_1 \sin\theta_1 = n_2 \sin\theta_2$ を自在に扱える。
2. **全反射の成立条件と臨界角**: 「屈折率の大きい媒質から小さい媒質へ」進むときにのみ全反射が起きる理由を理解し、臨界角 $\sin\theta_c = \frac{n_2}{n_1}$ を計算できる。
3. **レンズの写像公式の完全マスター**: $\frac{1}{a} + \frac{1}{b} = \frac{1}{f}$ における実像（$b > 0$）と虚像（$b < 0$）、凸レンズ（$f > 0$）と凹レンズ（$f < 0$）の符号ルールを完璧に使いこなせる。

## 2. 現象のしくみ

### なぜ光は境界で曲がるのか？
光の屈折の本質は、 **「物質によって光の進むスピード（光速）が異なる」** ことにあります。
* 真空中での光速: $c \approx 3.0 \times 10^8\,\text{m/s}$
* 水の中での光速: 約 $\frac{3}{4}c$（遅くなる！）
* ガラスの中での光速: 約 $\frac{2}{3}c$（さらに遅くなる！）

道路を走る車が、斜めに泥沼（進みにくい場所）に突入した場面を想像してください。
泥沼に先に突っ込んだ片側のタイヤだけが急減速するため、車全体が進行方向をグッと曲げられます。
これと全く同じ原理で、光波の波面が遅い媒質に突入するときに進路が曲がるのです。

## 3. 基本法則・公式

### ① 屈折率の定義とスネルの法則
真空中での光の速さを $c$、ある媒質中での光の速さを $v$ とするとき、その媒質の **絶対屈折率 $n$** は：

$$n = \frac{c}{v} > 1$$

媒質1（屈折率 $n_1$）から媒質2（屈折率 $n_2$）へ光が入射するとき、入射角 $\theta_1$ と屈折角 $\theta_2$ の間には **スネルの法則** が成り立ちます：

$$\frac{\sin\theta_1}{\sin\theta_2} = \frac{n_2}{n_1} = \frac{v_1}{v_2} = \frac{\lambda_1}{\lambda_2} = {}_1n_2$$

連比の形（掛け算の形）で覚えると分母分子のミスを完全に防げます：

$$n_1 \sin\theta_1 = n_2 \sin\theta_2$$

* **屈折しても変わらないもの**:**振動数 $f$**（光の色は物質に入っても変化しない！）
* **屈折して変化するもの**:**速さ $v$ と波長 $\lambda$**（屈折率 $n$ が大きい媒質ほど、波長は $\lambda' = \lambda/n$ に縮む）

---

### ② 臨界角と全反射
屈折率の大きい媒質（$n_1$：水やガラス）から、屈折率の小さい媒質（$n_2$：空気）へ光が進むとき、屈折角 $\theta_2$ は入射角 $\theta_1$ よりも大きくなります。
入射角 $\theta_1$ を徐々に大きくしていくと、やがて **屈折角 $\theta_2$ が直角 $90^\circ$（境界面すれすれ）に達する限界の角度**があります。このときの入射角を**臨界角 $\theta_c$** と呼びます。

スネルの法則に $\theta_2 = 90^\circ$（$\sin 90^\circ = 1$）を代入すると：

$$n_1 \sin\theta_c = n_2 \sin 90^\circ \implies \sin\theta_c = \frac{n_2}{n_1}$$

#### 全反射の条件
入射角 $\theta_1$ が臨界角 $\theta_c$ を超えると（$\theta_1 \ge \theta_c$）、光は媒質2へ一切透過できなくなり、 **境界面で100%完全に反射（全反射）** されます。
* 成立条件： **$n_1 > n_2$（密な媒質から疎な媒質へ進むときのみ！）**

---

### ③ レンズの写像公式
物体からレンズまでの距離を $a$、レンズから像までの距離を $b$、レンズの焦点距離を $f$ とするとき：

$$\frac{1}{a} + \frac{1}{b} = \frac{1}{f}$$

#### 倍率 $m$
像の高さと物体の高さの比（倍率）は：

$$m = \frac{|b|}{a}$$

#### 符号の超重要ルール表（受験の生命線！）

| 記号 | 正（$+$）の意味 | 負（$-$）の意味 |
| :---: | :--- | :--- |
| **$a$** | 通常の物体（レンズの前方） | （複数のレンズの組み合わせでの虚物体） |
| **$b$** |**実像**（レンズの後方・スクリーンに映る・倒立） |**虚像**（レンズの前方・目でのぞいて見える・正立） |
| **$f$** |**凸レンズ**（集光性） |**凹レンズ**（発散性） |

---

### ④ 3本の代表光線による作図法
作図により像の位置と大きさを求めるには、物体の先端から出る以下の3本の光線のうち、 **任意の2本** の交点を探します。

1. **光軸に平行に進む光線**: レンズを通過後、**後方焦点 $\text{F}'$ を通る**（凸レンズの場合）。
2. **レンズの中心 $\text{O}$ を通る光線**: 屈折せずに**真っ直ぐ直進**する。
3. **前方焦点 $\text{F}$ を通る光線**: レンズを通過後、**光軸に平行に進む**。

## 4. 成立条件と注意点

### 焦点位置 $f$ による凸レンズの像の激変
凸レンズの前に置く物体の位置 $a$ によって、現れる像が劇的に変化します：
* **$a > 2f$（遠く）**: $f < b < 2f$ の位置に**縮小された倒立実像**（カメラの原理）。
* **$a = 2f$**: $b = 2f$ の位置に**等倍（$m = 1.0$）の倒立実像**。
* **$f < a < 2f$**: $b > 2f$ の位置に**拡大された倒立実像**（映画館のプロジェクターの原理）。
* **$a = f$（焦点上）**: 光線が平行になり**像は結ばない（無限遠）**。
* **$a < f$（焦点の内側）**: レンズの前方に**拡大された正立虚像**（虫眼鏡の原理）。

## 6. 例題での使い方（完全オリジナル）

### 【例題】直角プリズムの全反射と凸レンズの組み合わせ

#### 問題設定
1. 屈折率 $n = 1.50$ のガラスで作られた直角二等辺三角形のプリズム $\text{ABC}$（$\angle\text{B} = 90^\circ$）が空気中（屈折率 $1.00$）に置かれている。面 $\text{AB}$ に垂直に入射した光は、斜面 $\text{AC}$ で全反射して面 $\text{BC}$ から垂直に出ていくことができるか。臨界角 $\theta_c$ を求めて判定せよ。
2. 焦点距離 $f = 15\,\text{cm}$ の薄い凸レンズがある。光軸上のレンズ前方 $a_1 = 45\,\text{cm}$ の位置に高さ $h = 4.0\,\text{cm}$ の物体を置いたとき、できる像の位置 $b_1\,[\text{cm}]$、像の種類（実像・虚像）、および像の高さ $h_1\,[\text{cm}]$ を求めよ。
3. この物体をレンズに近づけ、レンズ前方 $a_2 = 10\,\text{cm}$ の位置に置いたとき、できる像の位置 $b_2\,[\text{cm}]$、像の種類、および像の高さ $h_2\,[\text{cm}]$ を求めよ。

---

#### 解答・解説

##### 設問(1)
* **ステップ1：斜面 $\text{AC}$ への入射角の幾何学的計算**
  面 $\text{AB}$ に垂直に入射した光は屈折せず直進し、斜面 $\text{AC}$ に達する。
  直角二等辺三角形であるから、斜面 $\text{AC}$ と光線のなす角は $45^\circ$ である。
  したがって、斜面の法線に対する **入射角は $\theta_1 = 45^\circ$** である。
* **ステップ2：ガラスから空気への臨界角 $\theta_c$ の計算**
  $$\sin\theta_c = \frac{n_{\text{空気}}}{n_{\text{ガラス}}} = \frac{1.00}{1.50} = \frac{2}{3} \approx 0.667$$
  一方、入射角 $\theta_1 = 45^\circ$ のサインの値は：
  $$\sin 45^\circ = \frac{1}{\sqrt{2}} \approx \frac{1}{1.414} \approx 0.707$$
* **比較**:
  $$\sin 45^\circ (0.707) > \sin\theta_c (0.667) \implies \theta_1 > \theta_c$$
  入射角が臨界角を超えているため、光は斜面 $\text{AC}$ で **100%全反射する**。**答**: 全反射できる（理由: $\sin 45^\circ \approx 0.707 > \sin\theta_c \approx 0.667$ より入射角が臨界角を超えるため）

---

##### 設問(2)
* **着眼点**: レンズの写像公式 $\frac{1}{a} + \frac{1}{b} = \frac{1}{f}$ に $a_1 = 45\,\text{cm}, f = 15\,\text{cm}$ を代入する。
* **計算**:
  $$\frac{1}{b_1} = \frac{1}{f} - \frac{1}{a_1} = \frac{1}{15} - \frac{1}{45} = \frac{3 - 1}{45} = \frac{2}{45}$$
  $$b_1 = \frac{45}{2} = +22.5\,\text{cm}$$
* **像の吟味**:
  * $b_1 > 0$（正）であるから、レンズの後方 $22.5\,\text{cm}$ の位置にできる **倒立実像** である。
  * 倍率:
    $$m_1 = \frac{|b_1|}{a_1} = \frac{22.5}{45} = 0.50\,\text{倍}$$
  * 像の高さ:
    $$h_1 = h \times m_1 = 4.0 \times 0.50 = 2.0\,\text{cm}$$

**答**: 位置: レンズ後方 $22.5\,\text{cm}$（$+22.5\,\text{cm}$）、種類:**倒立実像**、高さ: $2.0\,\text{cm}$

---

##### 設問(3)
* **着眼点**: 物体距離 $a_2 = 10\,\text{cm}$ は焦点距離 $f = 15\,\text{cm}$ の内側にある（$a_2 < f$）。
* **計算**:
  $$\frac{1}{b_2} = \frac{1}{f} - \frac{1}{a_2} = \frac{1}{15} - \frac{1}{10} = \frac{2 - 3}{30} = -\frac{1}{30}$$
  $$b_2 = -30\,\text{cm}$$
* **像の吟味**:
  * $b_2 < 0$（負）であるから、レンズの前方（物体と同じ側）$30\,\text{cm}$ の位置にできる **正立虚像** である。
  * 倍率:
    $$m_2 = \frac{|b_2|}{a_2} = \frac{30}{10} = 3.0\,\text{倍}$$
  * 像の高さ:
    $$h_2 = h \times m_2 = 4.0 \times 3.0 = 12\,\text{cm}$$

**答**: 位置: レンズ前方 $30\,\text{cm}$（$-30\,\text{cm}$）、種類:**正立虚像**、高さ: $12\,\text{cm}$

## 7. 受験生が陥りやすい誤解・つまずき

### 誤解1：「凸レンズの上半分を手で隠すと、実像の上半分が消えて見えなくなる」
* **国公立大・共通テストの超頻出ひっかけ問題です！**
* **正しい理解**: 物体の1点から出た光は、レンズの「あらゆる部分（全面）」を通って像の1点へと集まります。
  * したがって、レンズの上半分を手で隠しても、下半分を通った光がちゃんと像を結ぶため、 **像の形は一切欠けずに全体がそのまま残ります**。
  * 変化するのは「集まる光の量が半分になること」、すなわち **像全体の明るさが暗くなるだけ** です！

### 誤解2：「実像はスクリーンなしでも肉眼で見えるのか？」
* **正しい理解**:
  * スクリーンを置けば、光が乱反射してどの角度からでも見えます。
  * スクリーンがなくても、実像ができる位置よりも後ろ（レンズから十分離れた位置）に目を置き、像に向かって焦点を合わせれば、 **空中に浮かんでいるかのように倒立実像を肉眼で直接見ることも可能** です。

## 8. 要点まとめ

::: tip 📌 幾何光学・波動光学の重要公式総まとめ
* **スネルの屈折の法則**:
  $$n_1 \sin\theta_1 = n_2 \sin\theta_2 \iff \frac{\sin\theta_1}{\sin\theta_2} = \frac{n_2}{n_1} = \frac{v_1}{v_2} = \frac{\lambda_1}{\lambda_2} = {}_1n_2$$
  ・振動数 $f$ は不変！波長 $\lambda$ は屈折率に反比例して縮む（$\lambda' = \lambda / n$）

* **全反射の条件**:
  1. 屈折率大 $\to$ 屈折率小（$n_1 > n_2$）の入射のみ起こる
  2. 臨界角 $\theta_c$: $\sin\theta_c = \dfrac{n_2}{n_1}$
  3. 入射角 $\theta_1 \ge \theta_c$ で光線が境界面で100%全反射！

* **レンズの写像公式**:
  $$\frac{1}{a} + \frac{1}{b} = \frac{1}{f}$$
  ・倍率: $m = \dfrac{|b|}{a}$  
  ・実像 ($b > 0$, 倒立): スクリーンに映る  
  ・虚像 ($b < 0$, 正立): 虫眼鏡、肉眼でのぞく  
  ・凸レンズ: $f > 0$、凹レンズ: $f < 0$
:::
