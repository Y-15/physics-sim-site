# 凹面鏡・凸面鏡と球面反射（写像公式）

自動車のバックミラーや道路のカーブミラーに使われる**凸面鏡**、コスメ用の拡大鏡や天体観測の巨大な反射望遠鏡に使われる**凹面鏡**は、光の屈折を利用するレンズとは異なり、**「反射の法則」**のみによって光を集束・発散させ、像を結びます。

本項では、球面鏡の幾何光学的原理、近軸光線近似による焦点距離 $f = \frac{R}{2}$ の導出、レンズの公式とまったく同一の形をもつ**「鏡の写像公式」**、および大学入試における光線作図と定石解法を徹底解説します。

---

## 1. 凹面鏡・凸面鏡のインタラクティブシミュレーター

凹面鏡（収束）と凸面鏡（発散）を切り替え、物体距離 $a$ や焦点距離 $|f|$ をスライダーで操作して、3本の代表光線（平行光線・頂点反射光線・中心光線）がどのように反射して実像・虚像を結ぶかをリアルタイムに観察できます。

### 2.1 幾何学的証明
光軸に平行に、高さ $h$（光軸に近い近軸光線 $h \ll R$）で入射した光線が鏡上の点 $P$ で反射する現象を考えます。
球面の法線は常に**球の中心（曲率中心 $C$）**を通る半径直線 $CP$ です。

1. **反射の法則**:
   入射角を $\theta$ とすると、法線 $CP$ に対する反射角も $\theta$ です。
2. **錯角の関係**:
   入射光線は光軸に平行なので、$\angle PCV = \theta$（錯角）です。
3. **二等辺三角形の形成**:
   反射光線が光軸と交わる点を $F$ とすると、$\triangle CFP$ において $\angle FCP = \theta$、$\angle FPC = \theta$ であるため、$\triangle CFP$ は $CF = FP$ の**二等辺三角形**となります。
4. **近軸光線近似（$h \ll R$）**:
   光線が光軸に十分近いとき、点 $P$ は頂点 $V$ に極めて近いため、$FP \approx FV$ とみなせます。
   $$CF \approx FV$$
   $CV = R$（曲率半径）であるため、点 $F$ は線分 $CV$ のちょうど**中点**に位置します：

$$\mathbf{f = \frac{R}{2}}$$

- **凹面鏡**: 光を前面に集めるため、実焦点 $f = +\frac{R}{2} > 0$
- **凸面鏡**: 光を前面に発散させ、奥から広がるように見えるため、虚焦点 $f = -\frac{R}{2} < 0$

## 3. 鏡の写像公式と倍率

### 3.1 写像公式（レンズの公式との完全一致）
鏡の頂点 $V$ から物体までの距離を $a$、像までの距離を $b$、焦点距離を $f$ とすると、凸レンズ・凹レンズと全く同一の**写像公式**が成立します。

$$\mathbf{\frac{1}{a} + \frac{1}{b} = \frac{1}{f}}$$

### 3.2 符号の絶対ルール（レンズとの決定的な違い）
レンズは「光が透過する」ため、レンズの反対側にできる像が実像（$b > 0$）でした。
しかし、鏡は「光が反射する」ため、**鏡の手前（反射側）にできる像が実像（$b > 0$）**となります！

| 記号 | 正（$+$）の場合 | 負（$-$）の場合 |
| :---: | :--- | :--- |
| **$a$** | 物体が鏡の前方にある（通常 $a > 0$） | 虚物体 |
| **$b$** | **実像**（鏡の手前に結像、スクリーンに映る） | **虚像**（鏡の奥に見える） |
| **$f$** | **凹面鏡**（光を集める） | **凸面鏡**（光を発散させる） |

### 3.3 倍率公式
像の大きさの倍率 $m$ は：

$$\mathbf{m = \frac{|b|}{a}}$$

- $b > 0$（実像）のとき：**倒立像**
- $b < 0$（虚像）のとき：**正立像**

## 4. 3大代表光線の作図法

像の位置を幾何学的に特定するには、次の3本のうち任意の2本の光線を引きます。

1. **平行光線**:
   光軸に平行に入射した光は、反射後に**焦点 $F$ を通過する**（凹面鏡）、または**奥の焦点 $F$ から放射状に出ていくように反射する**（凸面鏡）。
2. **頂点反射光線**:
   鏡の頂点 $V$ に入射した光は、光軸を法線として**対称な角で反射する**（入射角＝反射角）。
3. **曲率中心光線**:
   曲率中心 $C$ を通って入射した光は、球面に対して**垂直（法線上）に入射するため、そのまま同じ経路を逆戻りする**。

## 5. 大学入試厳選例題

### 例題1：凹面鏡による実像と虚像の結像（標準〜典型）

<div class="problem-card">
  <div class="problem-header">
    <span class="badge-exam">国公立大・標準レベル</span>
    <strong>問題：曲率半径 60 cm の凹面鏡の結像</strong>
  </div>
  <p>
    曲率半径 $R = 60\text{ cm}$ の凹面鏡がある。
  </p>
  <ol>
    <li>この凹面鏡の焦点距離 $f$ [$\text{cm}$] を求めよ。</li>
    <li>鏡の前方 $45\text{ cm}$ の位置に高さ $6.0\text{ cm}$ のろうそくを立てた。像ができる位置（鏡の頂点からの距離）、像の種類（実像または虚像、正立または倒立）、および像の高さを求めよ。</li>
    <li>次に、ろうそくを鏡の前方 $20\text{ cm}$ に近づけた。像の位置、種類、および像の高さを求めよ。</li>
  </ol>
</div>

#### 【思考プロセス・完全解答】

**1. 焦点距離 $f$**
凹面鏡の焦点距離は曲率半径の半分です：
$$f = \frac{R}{2} = \frac{60}{2} = \mathbf{+30\text{ cm}}$$

**2. $a = 45\text{ cm}$ のときの像**
物体距離 $a = 45\text{ cm}$、$f = 30\text{ cm}$ を写像公式に代入します：
$$\frac{1}{45} + \frac{1}{b} = \frac{1}{30} \implies \frac{1}{b} = \frac{1}{30} - \frac{1}{45} = \frac{3 - 2}{90} = \frac{1}{90}$$
$$b = \mathbf{+90\text{ cm}}$$
- $b > 0$ であるため、**鏡の前方 $90\text{ cm}$ の位置に「倒立実像」**ができます。
倍率 $m$ は：
$$m = \frac{|b|}{a} = \frac{90}{45} = 2.0\text{ 倍}$$
したがって、像の高さは：
$$h' = 6.0 \times 2.0 = \mathbf{12\text{ cm}}$$

**3. $a = 20\text{ cm}$ のときの像**
ろうそくが焦点の内側（$a < f = 30\text{ cm}$）に入った場合：
$$\frac{1}{20} + \frac{1}{b} = \frac{1}{30} \implies \frac{1}{b} = \frac{1}{30} - \frac{1}{20} = \frac{2 - 3}{60} = -\frac{1}{60}$$
$$b = \mathbf{-60\text{ cm}}$$
- $b < 0$ であるため、**鏡の奥 $60\text{ cm}$ の位置に「正立虚像」**ができます。
倍率 $m$ は：
$$m = \frac{|-60|}{20} = 3.0\text{ 倍}$$
したがって、像の高さは：
$$h' = 6.0 \times 3.0 = \mathbf{18\text{ cm}}$$

### 例題2：凸面鏡（カーブミラー）の視野と結像（難関大・応用）

<div class="problem-card">
  <div class="problem-header">
    <span class="badge-exam">難関国公立大・頻出</span>
    <strong>問題：凸面鏡による虚像と倍率の極限</strong>
  </div>
  <p>
    曲率半径 $R$ の凸面鏡の主軸上、鏡の前方距離 $a$ の位置に物体がある。
  </p>
  <ol>
    <li>像のできる位置 $b$ を $a$ と $R$ を用いて表せ。また、像が常に正立虚像となることを示せ。</li>
    <li>倍率 $m$ を $a$ と $R$ で表し、$a > 0$ において常に $m < 1$（常に縮小像）となることを示せ。</li>
    <li>物体を無限遠（$a \to \infty$）に遠ざけたとき、像の位置および倍率はどうなるか。カーブミラーが広い視野を映し出せる理由を説明せよ。</li>
  </ol>
</div>

#### 【思考プロセス・完全解答】

**1. 像の位置 $b$ と虚像の証明**
凸面鏡の焦点距離は $f = -\frac{R}{2}$ です。
写像公式 $\frac{1}{a} + \frac{1}{b} = \frac{1}{f}$ より：
$$\frac{1}{b} = \frac{1}{f} - \frac{1}{a} = -\frac{2}{R} - \frac{1}{a} = -\frac{2a + R}{aR}$$
$$b = \mathbf{-\frac{aR}{2a + R}}$$
$a > 0$、$R > 0$ であるため、分子・分母はともに正であり、常に **$b < 0$** となります。
したがって、凸面鏡の像は物体の位置に関わらず**常に鏡の奥にできる正立虚像**となります。

**2. 倍率 $m$ と $m < 1$ の証明**
倍率 $m$ は：
$$m = \frac{|b|}{a} = \frac{\frac{aR}{2a + R}}{a} = \mathbf{\frac{R}{2a + R} = \frac{1}{1 + \frac{2a}{R}}}$$
$a > 0$、$R > 0$ より $\frac{2a}{R} > 0$ であるため、分母は常に $1$ より大きくなります。
したがって：
$$m < 1$$
凸面鏡の像は、**常に実物より小さく縮小された正立像**になります。

**3. 無限遠（$a \to \infty$）の極限とカーブミラーの物理**
$a \to \infty$ のとき：
$$\lim_{a \to \infty} b = \lim_{a \to \infty} \left(-\frac{R}{2 + \frac{R}{a}}\right) = -\frac{R}{2} = f$$
$$\lim_{a \to \infty} m = \lim_{a \to \infty} \frac{1}{1 + \frac{2a}{R}} = 0$$
- 物体を無限に遠ざけても、像は鏡の奥の焦点面（距離 $|f| = \frac{R}{2}$）より奥には行かず、$0 < |b| < \frac{R}{2}$ の狭い空間に**遠方の全景観がぎゅっと縮小されて凝縮**されます。
- これにより、限られた小さな鏡面の中に広大な範囲の車や歩行者を同時に映し出すことができ、死角を劇的に減らす「カーブミラー」として理想的に機能します。

## 6. まとめ

| 項目 | 凹面鏡（収束） | 凸面鏡（発散） |
| :--- | :--- | :--- |
| **焦点距離 $f$** | **$f = +\frac{R}{2} > 0$** | **$f = -\frac{R}{2} < 0$** |
| **写像公式** | $\frac{1}{a} + \frac{1}{b} = \frac{1}{f}$ | $\frac{1}{a} + \frac{1}{b} = \frac{1}{f}$ |
| **像の性質 ($a > f$)** | **倒立実像** ($b > 0$, 鏡の手前) | （常に縮小正立虚像） |
| **像の性質 ($a < f$)** | **拡大正立虚像** ($b < 0$, 鏡の奥) | **縮小正立虚像** ($b < 0$, 鏡の奥) |
| **主な用途** | 反射望遠鏡、コスメ拡大鏡 | 道路カーブミラー、車バックミラー |
