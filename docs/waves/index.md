# 🌊 波動：定常波・重ね合わせ・ドップラー効果

高校物理「波動」の最重要テーマ3つを、リアルタイムシミュレーターで体感しよう！

<WavesSim />

::: tip 実験のポイント
1. **定常波タブ**: 倍振動 n を変えると腹と節の数が変わります。n=1 が基本振動（基音）です。  
2. **重ね合わせタブ**: 逆方向・同じ振動数 → 定常波。同方向・近い振動数 → うなりが聞こえる！  
3. **ドップラータブ**: 音源速度を上げると f' が大きく（高く）なることを確認しましょう。
:::

## 1. 定常波のしくみ

### 1.1 定常波とは？

**定常波**（Standing Wave）は、同じ振動数・振幅を持つ 2 つの波が**逆方向に進んで重なる**ときに生じます。
山も谷も移動せず、「その場で振動する」のが特徴です。

| 位置 | 名称 | 変位 |
|------|------|------|
| 変位が常に 0 | **節** (Node) | $y = 0$ |
| 変位が最大 | **腹** (Antinode) | $y = \pm A$ |

### 1.2 定常波の式

正弦波 $y_1 = A\sin(kx - \omega t)$ と反射波 $y_2 = A\sin(kx + \omega t)$ を重ねると：

$$y = y_1 + y_2 = 2A\sin(kx)\cos(\omega t)$$

$\sin(kx)$ が**振幅分布（空間部分）**、$\cos(\omega t)$ が**振動（時間部分）**を表します。

## 2. 弦・気柱の共鳴条件

### 2.1 両端固定の弦（ギター・バイオリン等）

両端が**固定端（節）**になる条件：

$$L = n \cdot \frac{\lambda}{2} \quad (n = 1, 2, 3, \ldots)$$

$$\therefore \quad \lambda_n = \frac{2L}{n}, \quad f_n = \frac{nv}{2L}$$

- $n=1$：基本振動（基音）
- $n=2$：第2倍振動（第1倍音）
- $n=3$：第3倍振動（第2倍音）

### 2.2 一端閉・一端開の気柱（クラリネット・フルート等）

閉端が**節**、開端が**腹**になる条件：

$$L = (2n-1) \cdot \frac{\lambda}{4} \quad (n = 1, 2, 3, \ldots)$$

$$\therefore \quad \lambda_n = \frac{4L}{2n-1}, \quad f_n = \frac{(2n-1)v}{4L}$$

**奇数倍の振動数しか共鳴しない**のが特徴です。

::: warning 試験のポイント
両端開管は「両端が腹」になるので $L = n\lambda/2$（両端固定と同じ式！）。  
混乱しがちなので、境界条件（節か腹か）から式を毎回導けるようにしましょう。
:::

## 3. 波の重ね合わせと干渉

### 3.1 重ね合わせの原理

複数の波が同じ媒質を伝わるとき、任意の点での変位は**各波の変位の和**になります。

$$y = y_1 + y_2$$

### 3.2 強め合い（同位相・建設的干渉）

2 つの波が出合う点で、位相差 $\Delta\phi = 0, 2\pi, 4\pi, \ldots$ のとき：

$$\Delta\phi = 2m\pi \quad (m = 0, \pm1, \pm2, \ldots)$$

**経路差** $\Delta L$ で表すと：$\Delta L = m\lambda$

### 3.3 弱め合い（逆位相・破壊的干渉）

位相差 $\Delta\phi = \pi, 3\pi, \ldots$ のとき：

$$\Delta L = \left(m + \frac{1}{2}\right)\lambda$$

### 3.4 うなり（ビート）

ほぼ同じ振動数 $f_1 \approx f_2$ の音が重なると、周期的に強弱が繰り返されます：

$$f_{\text{beat}} = |f_1 - f_2|$$

## 4. ドップラー効果

### 4.1 ドップラー効果の公式

音源が速度 $v_s$（観測者方向を正）、観測者が速度 $v_o$（音源方向を正）で動くとき、
観測される振動数 $f'$ は：

$$\boxed{f' = \frac{V + v_o}{V - v_s} f_0}$$

| 記号 | 意味 |
|------|------|
| $V$ | 音速（常温で約 340 m/s） |
| $v_s$ | 音源の速度（音源→観測者向きが正） |
| $v_o$ | 観測者の速度（観測者→音源向きが正） |
| $f_0$ | 音源が静止している場合の振動数 |

### 4.2 符号の決め方

::: tip 符号の覚え方
**分子** $V + v_o$：観測者が音源に**近づく**（$+$）と聞こえる音の数が増える → $f'$ 上昇  
**分母** $V - v_s$：音源が観測者に**近づく**（$+$）と波長が縮む → $f'$ 上昇
:::

#### 例題：救急車の問題

救急車（$f_0 = 800\,\text{Hz}$）が $v_s = 30\,\text{m/s}$ で接近してくるとき、
静止した観測者が聞く振動数は？

$$f' = \frac{340 + 0}{340 - 30} \times 800 = \frac{340}{310} \times 800 \approx 877\,\text{Hz}$$

### 4.3 壁での反射を使う問題

音源から出た音が壁に反射して戻ってくる場合：
1. 音源→壁：壁を「静止した観測者」として $f_{\text{wall}}$ を求める
2. 壁→観測者：壁を「静止した音源」（振動数 $f_{\text{wall}}$）として $f'$ を求める

## 5. 入試頻出のまとめ

| テーマ | 公式 | 特徴 |
|--------|------|------|
| 定常波（両端固定） | $f_n = nv/2L$ | 腹 $n$ 個、節 $n+1$ 個 |
| 定常波（一端閉） | $f_n = (2n-1)v/4L$ | 奇数倍のみ共鳴 |
| ドップラー効果 | $f' = (V+v_o)/(V-v_s) \cdot f_0$ | 符号は「近づく→分子+、分母-」 |
| うなり | $f_{beat} = |f_1 - f_2|$ | 共通テストでうなり数を問う |
| 重ね合わせ | $\Delta L = m\lambda$（強）, $(m+1/2)\lambda$（弱） | ヤングの実験、薄膜干渉 |
