# 🎓 大学物理（理工系・院試・専門基礎）ポータル

<div class="lead">
「高校物理では公式として暗記していた式が、なぜ成り立つのか？」<br>
「微積分や微分方程式、ベクトル解析を使うと、物理の世界はどう見通せるのか？」<br>
大学物理は、自然現象を少数の根本原理から<strong>数学的に演繹（えんえき）し、統一的に記述する体系</strong>です。<br>
当サイトでは、高校物理（大学受験・直感的理解）と大学物理（厳密な数理体系）を<strong>完全に分離</strong>し、理工系学部生・院試受験生・社会人の学び直しに最適な専用コンテンツを提供します。
</div>

## 🧭 高校物理と大学物理の本質的な違い

<div class="comparison-grid">

<div class="comparison-card hs-card">
  <div class="card-badge">🏫 高校物理（物理基礎・物理）</div>
  <h3>直感と代数による現象理解</h3>
  <ul>
    <li><strong>数学的道具</strong>: 初等代数、三角関数、比例・反比例、グラフの傾き・面積（$v-t$ グラフ）</li>
    <li><strong>運動方程式</strong>: $ma = F$（加速度 $a$ を定数または平均値として処理）</li>
    <li><strong>電磁気</strong>: クーロンの法則、フレミングの左手の法則、レンツの法則を個別の規則として適用</li>
    <li><strong>熱力学</strong>: 状態方程式 $PV = nRT$ と第1法則 $Q = \Delta U + W$ を algebraic に解く</li>
    <li><strong>目標</strong>: 共通テスト・国公立大学2次試験での立式力と定性的な物理感覚の涵養</li>
  </ul>
  <a class="switch-link" href="/mechanics/index">👉 高校物理カリキュラム・シミュレーター一覧へ</a>
</div>

<div class="comparison-card univ-card">
  <div class="card-badge">🎓 大学物理（理工系教養・専門）</div>
  <h3>微分積分・ベクトル解析による普遍的体系</h3>
  <ul>
    <li><strong>数学的道具</strong>: 常微分方程式、多重積分、ベクトル解析（$\nabla, \text{div}, \text{rot}$）、線形代数・演算子</li>
    <li><strong>運動方程式</strong>: $m\frac{d^2\vec{r}}{dt^2} = \vec{F}(\vec{r}, \vec{v}, t)$ を解く微分方程式問題</li>
    <li><strong>電磁気</strong>: 4つのマクスウェル偏微分方程式から電磁場と光（電磁波）を統一的に演繹</li>
    <li><strong>熱・統計力学</strong>: 熱力学関数とルジャンドル変換、ミクロな分配関数 $Z$ からマクロな物性を導出</li>
    <li><strong>目標</strong>: 理工系学部定期試験、大学院入試（院試）、最先端科学技術・工学の基礎力確立</li>
  </ul>
  <a class="switch-link" href="#curriculum">👇 大学物理 講義・演習問題一覧へ</a>
</div>
