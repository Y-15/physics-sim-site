# 🎲 3次元オセロ（3D Reversi）
### 〜 3次元ベクトル空間の把握力と戦略的思考を鍛える立体リバーシ 〜

高校物理の力学（3次元衝突や剛体の回転運動）、電磁気（立体の磁力線・ローレンツ力）、原子物理（3次元結晶格子やブラッグ反射）では、**「$x, y, z$ の3次元空間を頭の中で立体的に思い描く力」**が極めて重要になります。

この**「3次元オセロ（3D Reversi）」**は、平面の8方向だけでなく、高さ方向や立体対角線を含む**全26方向**の挟み込みを直感的に探索できる本格的な立体思考対戦ゲームです。CPU対戦（初級・中級・上級）、1台での2人対戦、そして**6桁のルームコードによるオンライン通信対戦**にも完全対応しています。

## 📖 3次元オセロのルールと物理的視点

### 1. 全26方向の挟み込み探索
平面のオセロは縦・横・斜めの「8方向」ですが、3次元立方体グリッドでは自分を中心とする $3 \times 3 \times 3 - 1 =$ **全26方向**で相手の石を挟むことができます。
* **軸平行（6方向）**: $\pm x$（左右）、$\pm y$（上下・層間）、$\pm z$（前後）
* **面対角線（12方向）**: $xy$ 平面、$yz$ 平面、$zx$ 平面それぞれの斜め4方向
* **立体主対角線（8方向）**: 立方体の重心を貫く立体対角線（例：$(\Delta x, \Delta y, \Delta z) = (\pm 1, \pm 1, \pm 1)$）

物理における**「位置ベクトル $\vec{r} = (x, y, z)$」**や結晶格子の配位数と同じ幾何学構造を成しています。

### 2. 8つの頂点（立体角）の絶大な支配力
平面オセロでは「4つの角（スミ）」を取ることが必勝の定石ですが、3次元オセロでは**立方体の「8つの頂点」**が絶対に裏返されない不動の絶対拠点となります。
頂点を確保すると、そこから伸びる3本の稜線・3つの面対角線・1本の主対角線の計7方向の防壁を一気に固めることができます。

### 3. 多層スライス（2D断面表示）と3D視点操作
奥まった層のマス目が見づらい・タップしづらい場合でも快適に遊べるよう、以下の補助機能を完備しています：
* **ドラッグ＆ホイール**: 3D空間を360度自由回転・拡大縮小
* **層間隔スライダー**: 各階層の高さを広げる「爆発分解表示」
* **レイヤー隔離ボタン**: 特定の階層（層1〜層4）だけをハイライト表示
* **右側2D断面マップ**: 各層の真上からの断面図を直接クリックして石を配置可能

## 🎮 3つのゲームモード

| モード | 説明 |
| :--- | :--- |
| **🤖 1人プレイ (CPU対戦)** | 初級（ランダム）・中級（位置重み＋獲得数）・上級（先読み評価関数）の3段階AIと対戦。先手（黒）・後手（白）を選択可能。 |
| **👥 2人オフライン (Pass & Play)** | 1台のPCやスマートフォン、タブレットを囲んで、黒と白を交互に指し継ぐ対面研究モード。 |
| **🌐 2人オンライン通信対戦** | **6桁のルームコード**を発行して友達にシェアするだけ。WebRTC (PeerJS) と Firestore によるリアルタイムP2P通信で、離れた相手とラグなし対局が楽しめます。 |

## ⌨️ 便利な操作方法・ショートカットキー

PCでプレイする場合、以下のキーボードショートカットで快適に操作できます：

| キー | 動作 |
| :---: | :--- |
| <kbd>R</kbd> | 3Dカメラ視点を初期位置にリセット |
| <kbd>Z</kbd> | 1手戻す（待った ※CPU・ローカル対戦時） |
| <kbd>F</kbd> | 全画面（フルスクリーン）の切り替え |
| <kbd>S</kbd> | 効果音（SE）の ON / OFF 切り替え |
| <kbd>M</kbd> | ゲームモード・通信ロビー設定を開く |
| <kbd>1</kbd> 〜 <kbd>4</kbd> (または <kbd>6</kbd>) | 指定した階層（層1〜層4）だけをハイライト表示 |
| <kbd>0</kbd> または <kbd>`</kbd> | すべての層を通常表示に戻す |
| <kbd>Esc</kbd> | モーダルを閉じる |
