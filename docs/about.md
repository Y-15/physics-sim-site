# このサイトについて

「**物理ラボ**」は、視覚と直感で学べるインタラクティブな物理学の解説サイトです。

高校生・大学受験生から、大学で力学や電磁気学を学ぶ大学生、物理をもう一度学び直したい社会人まで、すべての方に「物理の面白さと直感的な納得」を届けることを目指しています。

---

## サイトの特徴

1. **動くシミュレーション**: 抽象的な数式を、スライダーやボタンで視覚化します。
2. **完全無料**: 誰でもいつでも、すべてのコンテンツを無料で利用できます。
3. **スマホ・タブレット対応**: 通学時間やすきま時間にも手軽に操作できます。
