# 📘 このサイトについて・高校物理学習ガイド & 活用術

「**高校物理シミュレーションラボ**」は、高校生・大学受験生・物理を学び直したいすべての方が、物理の公式や自然現象を「**動かして直感的に完全理解する**」ための完全無料のオープン学習プラットフォームです。

---

## 🎯 なぜ「動くシミュレーション」なのか？

高校物理で多くの受験生がつまずく最大の原因は、**「教科書の静止画と抽象的な数式だけでは、物体の動きや電磁場、波の重なりが頭の中で立体的にイメージできないこと」**にあります。

当サイトでは以下の3大コンセプトを徹底追求しています：

1. **リアルタイム対話型シミュレーション**:
   初速度・角度・質量・ばね定数・磁場・波長などをスライダーで自由に変更し、現象の変化をその場で観察できます。
2. **公式の「完全導出」ステップ**:
   なぜその公式が成り立つのか？ 丸暗記を廃し、微分積分や幾何学的ベクトル分解に基づいた本質的な導出を丁寧に記載しています。
3. **大学入試 厳選例題（全1,000問データベース連携）**:
   基礎の確認から共通テスト、東大・京大・旧帝大・医学部レベルの難関大二次試験記述問題まで、動くシミュレーターと連動した詳細な解答解説を提供しています。

## 📈 高校物理で偏差値70を突破する3段階学習法

```
【Step 1: 現象の直感理解】  当サイトのシミュレーターを動かしてパラメーター変化と挙動を体感
       ↓
【Step 2: 公式の完全導出】  なぜその式になるかを自力で白紙に導出（共通テスト・二次記述対策）
       ↓
【Step 3: 厳選入試演習】   全1,000問の演習問題集で典型パターンと応用思考力を定着
```

### 共通テスト物理で満点を取る「3大チェック習慣」
1. **極限チェック（Extreme Case Check）**:
   求めた文字式の角度を $0^\circ$ や $90^\circ$、質量を $0$ や $\infty$ に極限操作したとき、直感的に明らかな状況（平地での滑走、自由落下など）と一致するか確かめる。
2. **次元解析（Dimensional Analysis）**:
   式の両辺の単位（$[m], [s], [kg]$ など）が合っているか確認する。
3. **エネルギー収支の確認**:
   失われた運動エネルギーは摩擦熱やジュール熱と一致しているか確認する。
