# このサイトについて・学習ガイド

「**高校物理シミュレーションラボ**」は、高校生・大学受験生が物理の公式や現象を「**動かして直感的に理解する**」ための完全無料学習プラットフォームです。

---

## 🎯 なぜ「動くシミュレーション」なのか？

高校物理で多くの受験生がつまずく最大の原因は、**「教科書の静止画と数式だけでは、物体の動きや波の伝わり方がイメージできないこと」** にあります。

当サイトでは：
1. **スライダーでパラメータ（初速度・角度・重力・質量など）を自由に変えられる**
2. **リアルタイムに運動の変化や数式計算（最高点・滞空時間・周期）が連動する**
3. **数式の導出ステップを省かず、共通テストや難関大二次試験の記述にも対応**

というアプローチで、丸暗記ではなく**「現象の本質を掴んで自力で解ける力」**を養います。

## 📚 高校物理 おすすめの学習ステップ

高校物理で効率よく偏差値60〜70を目指すための標準的な学習ロードマップです：

| ステップ | 目標 | おすすめ参考書・学習法 |
| :--- | :--- | :--- |
| **Step 1: 現象のイメージ掴み** | 公式の成り立ちと意味を理解する | 当サイトのシミュレーター ＋ 『物理のエッセンス』や『宇宙一わかりやすい高校物理』 |
| **Step 2: 基礎〜標準問題演習** | 定番の解法パターンを定着させる | 『良問の風 物理頻出・標準入試問題集』 |
| **Step 3: 入試実戦・難関大演習** | 思考力・記述力を完成させる | 『名問の森 物理』『重要問題集』 |
