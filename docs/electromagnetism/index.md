## 📚 電磁気学 テーマ別ナビゲーション（全14分野）

<div class="topic-grid">

### 1. 静電気と電場・電位
* **[⚡ クーロンの法則・電場（電界）と電位](/electromagnetism/field)**  
  2つの点電荷がつくる電場ベクトル・電気力線・等電位線の2Dリアルタイムマップ。点電荷をドラッグ移動させながら、電場（ベクトル合成）と電位（スカラー和）の本質的な違いを体感できます。

### 2. コンデンサー回路
* **[🔋 コンデンサーの回路と静電エネルギー・誘電体](/electromagnetism/capacitor)**  
  平行平板コンデンサーの極板間隔 $d$、面積 $S$、誘電体挿入、スイッチON/OFF（電圧一定 vs 電荷一定）のリアルタイムシミュレーター。極板間引力 $F=\frac{1}{2}QE$、静電エネルギー収支の完全理解。

### 3. 直流回路と回路網解析
* **[💡 直流回路とキルヒホッフの法則・非オーム抵抗・ホイートストンブリッジ](/electromagnetism/circuit)**  
  キルヒホッフ第1・第2法則による2電源回路網、電球の非線形 $I$-$V$ 特性と負荷線のリアルタイム作図、ホイートストンブリッジの平衡条件 $R_1 R_4 = R_2 R_3$ の動的シミュレーター。

### 4. 磁場と荷電粒子の運動・加速器
* **[🌀 磁場中の荷電粒子の運動・ローレンツ力](/electromagnetism/lorentz)**  
  一様磁場中の等速円運動（半径 $r=\frac{mv}{qB}$、周期 $T=\frac{2\pi m}{qB}$）と、らせん運動のリアルタイム3D/2Dシミュレーター。
* **[🔬 トムソンの比電荷測定と速度セレクター](/electromagnetism/thomson)**  
  直交電磁場による速度選択条件 $v = E/B$、および電場偏向・磁場偏向による電子の比電荷 $e/m$ 導出のリアルタイムシミュレーション。
* **[⚡ サイクロトロン（粒子加速器）とローレンツ力](/electromagnetism/cyclotron)**  
  D型電極間の高周波電場と磁場による荷電粒子加速、サイクロトロン周波数 $f = \frac{qB}{2\pi m}$、最大運動エネルギーの完全解析。
* **[🧲 ベータトロン（誘導加速器）と電磁誘導加速](/electromagnetism/betatron)**  
  変動磁場が誘起する渦電場による電子加速、軌道半径を一定に保つウィデローの $2:1$ 則（$\Delta \Phi = 2\pi R^2 \Delta B$）の解明。

### 5. 電流と磁場・電磁力
* **[🧲 電磁力と平行電流間に働く力（アンペール力）](/electromagnetism/magnetic-force)**  
  磁場中の直線電流が受ける力 $F = I B L \sin\theta$、平行電流間に働く引力・斥力 $F/L = \frac{\mu_0 I_1 I_2}{2\pi r}$、1アンペアの定義シミュレーター。
* **[🧲 電流がつくる磁場とアンペールの法則](/electromagnetism/magnetic-field)**  
  直線電流・円形電流・ソレノイドコイルがつくる磁場の合成、ビオ・サバールの法則とアンペールの周回積分の可視化。
* **[🧲 ホール効果とキャリア判定](/electromagnetism/hall-effect)**  
  半導体・金属中のキャリア（電子 vs 正孔）に働くローレンツ力とホール電圧 $V_H$、キャリア密度 $n$ の測定シミュレーター。

### 6. 電磁誘導と交流・振動回路
* **[🧲 電磁誘導の法則・レンツの法則と導線棒の運動](/electromagnetism/induction)**  
  レール回路上の導線棒の誘導起電力 $V=vBl$、終端速度 $v_{\text{terminal}}$、外力の仕事率とジュール熱の一致、レンツの法則シミュレーター。
* **[⚡ 自己誘導とコイルの過渡現象・RL回路](/electromagnetism/self-induction)**  
  逆起電力 $V = -L \frac{dI}{dt}$、RL回路の過渡応答、時定数 $\tau = L/R$、コイルに蓄えられる磁気エネルギー $U = \frac{1}{2}LI^2$ の完全導出。
* **[〰️ 交流回路とRLC直列回路・共振](/electromagnetism/ac-circuit)**  
  交流の瞬時値・実効値、リアクタンス（$\omega L$ と $1/\omega C$）、インピーダンス $Z$、フェーザー図（ベクトル図）と直列共振 $\omega_0 = 1/\sqrt{LC}$。
* **[⚡ LC振動回路と電磁振動](/electromagnetism/lc-oscillation)**  
  コンデンサーの静電エネルギーとコイルの磁気エネルギーの相互変換、振動周期 $T = 2\pi\sqrt{LC}$、単振動とのアナロジー。
