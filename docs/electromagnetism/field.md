# クーロンの法則・電場（電界）と電位

<div class="lead">
冬場にドアノブに触れたときの「パチッ」という静電気、下敷きで髪の毛をこすると逆立つ不思議。<br>
目に見えない電気の世界を数学的に解き明かすカギが、<strong>電場（電界）</strong>と<strong>電位</strong>です。
「電場は力のベクトル、電位は高さ（エネルギー）のスカラー」。この2大概念の決定的な違いを、動く電気力線シミュレーターで直感的にマスターしましょう。
</div>

---

## 1. 身近な現象と到達目標

### 身近な現象
* **静電気の引き合い・反発**: プラスチック下敷きで髪の毛をこすると、髪の毛同士が反発して広がり、下敷きに吸い寄せられる。
* **雷（落雷）**: 雲と地面の間に莫大な電位差（電圧）が生じ、空気を突き破って大電流が流れる現象。
* **タッチパネル**: スマートフォンの画面は、指先の接触による静電容量（電荷の分布）の変化を感知して動いている。

### 学習の到達目標
1. **電場と電位の峻別**: 電場 $\vec{E}$（向きを持つベクトル、単位 $\text{N/C}$ または $\text{V/m}$）と、電位 $V$（符号付きの大きさのみを持つスカラー、単位 $\text{V}$）を明確に区別して計算できる。
2. **重ね合わせの原理**: 複数の電荷が存在するとき、電場は**矢印のベクトル合成**、電位は**単なる足し算（スカラー和）**で求められる。
3. **電気力線と等電位線の直交性**: 電気力線が電位の高い方から低い方へ向かい、等電位線と常に直交する幾何学的性質を理解する。

---

## 2. 現象のしくみ

### 遠隔作用から「近接作用」へ
離れた2つの電荷が引き合ったり反発したりするとき、昔の物理学者は「何もない空間を飛び越えて力が瞬時に伝わる（遠隔作用）」と考えていました。
しかし現代物理学（ファラデーやマクスウェル）では、次のように考えます：

1. 電荷 $Q$ が置かれると、**周りの空間そのものが歪み（電場が発生し）**、
2. その歪んだ空間に別の電荷 $q$ を置くことで、**その場所の空間から力 $\vec{F} = q\vec{E}$ を受ける**。

このように「空間を介して隣から隣へと力が伝わる」という考え方を**近接作用**と呼びます。

### 電位＝電気的な「標高（高さ）」
重力の世界では「高い場所にある物体は位置エネルギー $U = mgh$ を持ち、低い谷底へ自然に転がり落ちる」のと同じように、
電気の世界でも**正電荷は「電位の高い山」から「電位の低い谷」へと自然に転がり落ちようとします**。
* **$+1\,\text{C}$ の正電荷を置いたときに、その場所が持っている静電気力による位置エネルギー**こそが**電位 $V\,[\text{V}]$** の正体です。

## 3. 基本法則・公式

### ① クーロンの法則（静電気力）
真空中で距離 $r\,[\text{m}]$ 離れた2つの点電荷 $q_1, q_2\,[\text{C}]$ の間に働く静電気力の大きさ $F\,[\text{N}]$ は：

$$F = k \frac{|q_1 q_2|}{r^2}$$

* $k$: クーロンの法則の比例定数（静電気力定数）
  $$k \approx 8.99 \times 10^9\,\text{N}\cdot\text{m}^2/\text{C}^2 \approx 9.0 \times 10^9\,\text{N}\cdot\text{m}^2/\text{C}^2$$
* **同種の電荷同士（$++$ または $--$）**: **斥力**（しりぞけ合う）
* **異種の電荷同士（$+-$）**: **引力**（引き合う）

> [!WARNING]
> 公式に代入するときは、電荷の正負符号は入れず**絶対値**で力の「大きさ」を求め、力の「向き」は同種・異種から作図で判断するのが受験計算で最もミスを防ぐコツです。

---

### ② 電場（電界） $\vec{E}$
電場の中のある点に $+1\,\text{C}$ の試験電荷を置いたとき、その電荷が受ける静電気力をその点の**電場** $\vec{E}$ と定義します。

$$\vec{F} = q \vec{E} \quad \Longleftrightarrow \quad \vec{E} = \frac{\vec{F}}{q}$$

* 単位：$[\text{N/C}]$ または $[\text{V/m}]$
* 点電荷 $Q\,[\text{C}]$ から距離 $r\,[\text{m}]$ 離れた点の電場の大きさ：
  $$E = k \frac{|Q|}{r^2}$$
  * $Q > 0$（正電荷）：電荷から外へ放射状に広がる向き
  * $Q < 0$（負電荷）：電荷へ向かって吸い込まれる向き

---

### ③ 電位 $V$ と位置エネルギー $U$
電場の中の基準点（通常は無限遠点 $\infty$）から、ある点まで外力で $+1\,\text{C}$ の電荷をゆっくり運ぶのに必要な仕事。

$$U = q V$$

* 単位：ボルト $[\text{V}] = [\text{J/C}]$
* 点電荷 $Q\,[\text{C}]$ から距離 $r\,[\text{m}]$ 離れた点の電位（無限遠を基準 $V(\infty) = 0$）：
  $$V = k \frac{Q}{r}$$
  ※電位の公式には、**電荷 $Q$ の正負の符号（$+$ や $-$）をそのまま代入します！**（正電荷のまわりは山 $V > 0$、負電荷のまわりは谷 $V < 0$）

---

### ④ 一様な電場と電位差
極板間のように、どこでも電場 $\vec{E}$ が一定（一様）で向きが揃っている領域において、距離 $d\,[\text{m}]$ だけ離れた2点間の電位差（電圧）$V\,[\text{V}]$ は：

$$V = E d \quad \Longleftrightarrow \quad E = \frac{V}{d}$$

---

### ⑤ 電気力線と等電位線
| 特徴 | 電気力線 | 等電位線（面） |
| :--- | :--- | :--- |
| **向き** | ＋電荷から出て、ー電荷へ入る | 向きはない（等高線と同じ） |
| **密度** | 線の密度が電場の強さ $E$ に比例する | 線の間隔が狭いほど急勾配（電場が強い） |
| **交差** | 途中で交わったり枝分かれしたりしない | 異なる電位の線同士は絶対に交わらない |
| **直交性** | **電気力線と等電位線は、至る所で互いに直交する** | |

## 4. 成立条件と注意点

### 点電荷の仮定
* クーロンの法則や点電荷の公式（$E = kQ/r^2, V = kQ/r$）は、電荷の幾何学的サイズが距離 $r$ に比べて十分に小さい「点電荷」に対してのみ厳密に成り立ちます。
* 金属球などの導体では、静電誘導によって表面に電荷が再配置されます（球対称であれば外部に対して中心に全電荷が集まった点電荷とみなせます）。

### ベクトル合成 vs スカラー和
* 複数の点電荷 $Q_1, Q_2, \dots$ があるとき：
  * **電場 $\vec{E}_{\text{全}} = \vec{E}_1 + \vec{E}_2 + \dots$** $\to$ **平行四辺形の法則によるベクトル合成！**
  * **電位 $V_{\text{全}} = V_1 + V_2 + \dots$** $\to$ **符号付きの普通の代数和（足し算）！**

### 観察のポイント
1. **電気双極子（$+3\,\mu\text{C}$ と $-3\,\mu\text{C}$）**:
   * 電気力線が正電荷から湧き出し、弧を描いて負電荷へと吸い込まれていく様子を観察してください。
   * 2つの電荷のちょうど真ん中の垂直二等分線上では、電位は常に $V = 0\,\text{V}$ ですが、電場は右向きに最大となります（「電位が0でも電場は0ではない！」の代表例）。
2. **同種電荷（$+3\,\mu\text{C}$ と $+3\,\mu\text{C}$）**:
   * 2つの電荷の間で電気力線が互いに反発し合って外側へ逃げていきます。
   * ちょうど中点では両者からの電場が完全に打ち消し合い、**電場 $E = 0$** になります。

## 6. 例題での使い方（完全オリジナル）

### 【例題】直線上にある2つの点電荷がつくる電場と電位

#### 問題設定
$x$ 軸上の点 $\text{A}\,(x = -a)$ に電気量 $+4Q\,(Q > 0)$ の点電荷を固定し、点 $\text{B}\,(x = +a)$ に電気量 $-Q$ の点電荷を固定した。
クーロンの法則の比例定数を $k$ とし、無限遠での電位を $0\,\text{V}$ とする。

1. $x$ 軸上で電場が $0$ となる点 $\text{P}_0$ の $x$ 座標を求めよ。
2. $x$ 軸上で電位が $0$ となる点 $\text{P}_1, \text{P}_2$ の $x$ 座標をすべて求めよ。

---

#### 解答・解説

##### 設問(1)
* **ステップ1：電場が $0$ になり得る領域の吟味**
  $x$ 軸を以下の3つの区間に分けて考える：
  1. $x < -a$（点 $\text{A}$ の左側）：
     $+4Q$ に近く、$-Q$ から遠い。$+4Q$ による電場（左向き）のほうが $-Q$ による電場（右向き）よりも常に圧倒的に大きいため、打ち消し合って $0$ になることはない。
  2. $-a < x < a$（点 $\text{A}$ と $\text{B}$ の間）：
     $+4Q$ からの電場は右向き、$-Q$ への電場も右向き。両方の電場が同じ右向きなので、和が $0$ になることは絶対にない。
  3. $x > a$（点 $\text{B}$ の右側）：
     $-Q$（近いが電荷小）からの電場は左向き、$+4Q$（遠いが電荷大）からの電場は右向き。
     距離の2乗の比と電荷の比が釣り合えば、**電場が $0$ になり得る！**

* **ステップ2：立式と計算**
  求める点の座標を $x\,(x > a)$ とする。
  * $+4Q$ からの距離は $r_1 = x - (-a) = x + a$
  * $-Q$ からの距離は $r_2 = x - a$
  
  電場の大きさが等しくなる条件：
  $$k \frac{4Q}{(x + a)^2} = k \frac{Q}{(x - a)^2}$$
  両辺を $kQ\,(>0)$ で割ると：
  $$\frac{4}{(x + a)^2} = \frac{1}{(x - a)^2}$$
  $x > a$ より $x + a > 0$ かつ $x - a > 0$ であるから、両辺の正の平方根をとる：
  $$\frac{2}{x + a} = \frac{1}{x - a}$$
  たすき掛けして整理する：
  $$2(x - a) = x + a \implies 2x - 2a = x + a \implies x = 3a$$

**答**: $x = 3a$

---

##### 設問(2)
* **ステップ1：電位の立式（スカラー和）**
  電位は向きのないスカラー量なので、単に足し合わせる：
  $$V(x) = k \frac{+4Q}{|x + a|} + k \frac{-Q}{|x - a|} = 0$$
  両辺を $kQ$ で割って移項すると：
  $$\frac{4}{|x + a|} = \frac{1}{|x - a|} \implies |x + a| = 4 |x - a|$$

* **ステップ2：絶対値を外して解く**
  $$x + a = \pm 4(x - a)$$
  * 複号が $+$ のとき（点 $\text{A}$ と $\text{B}$ の内分点）：
    $$x + a = 4x - 4a \implies 3x = 5a \implies x = \frac{5}{3}a$$
    （$-a < \frac{5}{3}a$ ではないので不適…ではなく、点 $\text{B}$ の右側で成立するか確認：$x = \frac{5}{3}a > a$ なので $|x+a|=\frac{8}{3}a, 4|x-a|=4\times\frac{2}{3}a=\frac{8}{3}a$ で適する！）
  * 複号が $-$ のとき（点 $\text{A}$ と $\text{B}$ の間）：
    $$x + a = -4(x - a) = -4x + 4a \implies 5x = 3a \implies x = \frac{3}{5}a$$
    （$-a < \frac{3}{5}a < a$ であり、適する！）

**答**: $x = \frac{3}{5}a, \;\; x = \frac{5}{3}a$

## 7. 受験生が陥りやすい誤解・つまずき

### 誤解1：「電位が $0\,\text{V}$ の場所は、電場も $0\,\text{N/C}$ になる」
* **最大の落とし穴です！**
  * 電位は「標高（高さ）」、電場は「斜面の傾きの急さ（勾配）」です。
  * 海抜 $0\,\text{m}$ の海岸線の急な崖をイメージしてください。標高は $0$ ですが、坂道は急峻です。
  * 電気双極子の中点では $V = 0$ ですが、電場は強烈に存在します。逆に、例題(1)の $x = 3a$ では電場は $0$（平坦）ですが、電位は $V = k\frac{4Q}{4a} - k\frac{Q}{2a} = k\frac{Q}{2a} > 0$ であり、$0$ ではありません。

### 誤解2：「クーロンの法則の分母をうっかり $r$ にしてしまう」
* **静電気力・電場**: 距離の**2乗に反比例**（$1/r^2$）
* **電位**: 距離の**1乗に反比例**（$1/r$）
* 次元と単位の対応を常に意識して混同を防ぎましょう。

## 8. 要点まとめ

::: tip 📌 電場と電位の重要公式総まとめ
* **クーロンの法則**:
  $$F = k \frac{|q_1 q_2|}{r^2} \quad [\text{N}]$$
  （※引力・斥力の向きは電荷の正負から幾何学的に判断）

* **電場（ベクトル量）**:
  $$E = k \frac{|Q|}{r^2} \quad [\text{N/C} \text{ または } \text{V/m}]$$
  ・正電荷から湧き出し、負電荷へ吸い込まれる  
  ・複数電荷がつくる合電場は**ベクトル合成（平行四辺形の法則）**

* **電位（スカラー量）**:
  $$V = k \frac{Q}{r} \quad [\text{V}]$$
  ・無限遠を基準 $V(\infty) = 0$、**$Q$ の符号（$\pm$）をそのまま代入**  
  ・複数電荷がつくる合電位は**単純なスカラー和（代数和）**

* **一様な電場と電位差**:
  $$V = E d \iff E = \frac{V}{d}$$
:::
