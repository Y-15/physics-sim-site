# 力学（高校物理）完全学習マップ

**力学（Mechanics）**は、高校物理全体の基礎となる最も重要で出題頻度の高い分野です。
物体が「なぜそのように運動するのか」をニュートンの運動法則、エネルギー保存則、運動量保存則という3大基本原理から解明します。

当サイトでは、力学の全17テーマすべてに対話型シミュレーターと数式導出、大学入試厳選例題を完備しています。苦手なテーマや確認したい現象をクリックして学習を始めましょう。

### 1. 直線運動・落体・投射
* **[🏎️ 等加速度直線運動とv-tグラフ](/mechanics/acceleration)**  
  <i>v</i>-<i>t</i> グラフの傾きが加速度、面積が移動距離。3大公式の完全理解と自由落下・鉛直投げ上げ・投げ下げの解法。
* **[🚀 斜方投射（放物運動の公式と軌道）](/mechanics/projectile)**  
  水平（等速）と鉛直（等加速度）の独立性。最高点到達時間・最高高度・水平到達距離の完全導出シミュレーター。
* **[🪂 空気抵抗を受ける物体の運動と終端速度](/mechanics/terminal-velocity)**  
  粘性抵抗（kv）と慣性抵抗（κ <i>v</i>²）、終端速度 <i>v</i><sub>term</sub>、雨滴落下とパラシュート開傘シミュレーター。

### 2. 運動方程式・摩擦・エネルギー
* **[⚙️ 運動の法則・連結物体の運動方程式と滑車](/mechanics/newton)**  
  ニュートンの3法則（慣性・運動・作用反作用）。内力と外力の見極め、2物体連立運動方程式。
* **[📐 摩擦力と斜面上の運動（摩擦角）](/mechanics/friction)**  
  静止摩擦力と最大摩擦力（μ<sub><i>s</i></sub> <i>N</i>）、動摩擦力（μ' <i>N</i>）、斜面の滑り出し条件と摩擦角 tanθ = μ<sub><i>s</i></sub>。
* **[⚡ 仕事・仕事率と力学的エネルギー保存則](/mechanics/energy)**  
  仕事の定義 <i>W</i> = <i>F</i> <i>s</i> cosθ、仕事と運動エネルギーの関係、保存力と位置エネルギー、非保存力がする仕事。

### 3. 単振動・衝突・運動量
* **[🔩 ばねの単振動（復元力とエネルギー）](/mechanics/spring)**  
  フックの法則、運動方程式から導く周期公式 <i>T</i> = 2π√(<i>m</i>/<i>k</i>)、振動中心における最大速度と端点での最大加速度。
* **[🕰️ 単振り子（等時性と周期公式）](/mechanics/pendulum)**  
  微小角近似 sinθ ≈ θ、復元力、等時性と周期公式 <i>T</i> = 2π√(<i>L</i>/<i>g</i>)。
* **[💥 運動量保存則と衝突（反発係数）](/mechanics/momentum)**  
  力積と運動量変化、内力相互作用による運動量保存則、はね返り係数 <i>e</i>、完全弾性衝突と非弾性衝突の力学的エネルギー損失。

### 4. 円運動・慣性力・万有引力
* **[🔄 等速円運動・向心加速度・向心力](/mechanics/circular)**  
  角速度 ω、周期 <i>T</i>、向心加速度 <i>a</i> = <i>r</i>ω² = <i>v</i>²/<i>r</i>、向心力、円錐振り子の解法。
* **[🎢 鉛直面内の円運動と宙返り・軌道離脱条件](/mechanics/vertical-loop)**  
  最下点初速 <i>v</i><sub>0</sub> ≥ √(5gR) による1周宙返り条件、最高点での垂直抗力 <i>N</i> ≥ 0、途中離脱角 cosθ = (2gR-<i>v</i><sub>0</sub>² / 3gR) とその後の放物線軌道シミュレーター。
* **[🚀 慣性力・見かけの重力・遠心力](/mechanics/inertia)**

* **[🪐 万有引力と人工衛星・ケプラー則](/mechanics/gravitation)**

### 5. 剛体・浮力・束縛運動・2体問題
* **[⚖️ 剛体のつり合いと力のモーメント](/mechanics/moment)**  
  並進のつり合い Σ <i>F</i> = 0 と回転のつり合い Σ <i>M</i> = 0、支点選択の極意、立てかけた棒の滑り出し限界。

* **[🌊 浮力とアルキメデスの原理・水圧](/mechanics/buoyancy)**

* **[⚖️ 2体問題・重心運動と相対運動（換算質量）](/mechanics/two-body)**
